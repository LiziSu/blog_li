  1. vue基本原理
    当创建一个vue实例时，vue2通过Object.defineProperty 重新定义data中的属性，当页面要使用对应属性的时候，首先进行依 赖收集，收集当前组件的watcher，如果属性发生变化会通知相关依赖进行更新操作。
    vue3中用proxy代替，因为其可以直接监听对象和数组的变化，而且有多种拦截方式。
  2. 双向数据绑定原理： 定义：数据绑定方式，数据层（model）和视图层（view）是双向的
    原理：通过数据劫持和发布订阅模式结合，核心是Object.defineProperty()方法
    通过Object.defineProperty()来劫持各个属性的setter，getter，在数据变动时发布消息给订阅者，触发相应的监听回调。
    Object.defineProperty()数据劫持的缺点：对一些属性操作（例如数组的大部分操作）是拦截不到的，vue3中用proxy拦截任何数据改变
  3. MVVM、MVC、MVP的区别 三者都是框架模式，设计的目标都是为了解决model和view的耦合问题
    MVC: 当model层发生变化时通知view层更新，当用户与页面产生交互时，controller中的事件触发器工作，调用model层修改model层， model层再去通知view层更新。
    MVP:MVC的进化模式，view并不直接使用model，通过presenter来进行。
    MVVM:model和view之间通过viewModel来联系，model中数据改变会触发view层的刷新，view的用户交互中改变的数据会在model中同步， model和viewModel之间有双向数据绑定的关系。
  4. computer和watch的区别
    computer：适用于进行数值计算，且依赖于其他数据；
    watch侦听器：观察作用，无缓存，适用于数据监听与响应式更新
  5. computed和methods的区别
    相同：同一个函数可以定义为method或者computed，结果相同
    区别：computed只有相关依赖发生变化才重新求值，method调用是总是执行的
  6. slot是什么？有什么作用？原理？
    插槽，作用：vue中的内容分发机制。分为3类：默认插槽（匿名插槽，没有指定name属性值的时候的默认插槽，一个组件内只能有一个）、 具名插槽（带有name属性的slot，一个组件内部可以有多个）、作用域插槽（可以是匿名也可以是具名，子组件渲染作用域插槽时，可以将 子组件内部的数据传给父组件，让父组件根据传来的数据决定如何渲染）
    原理：当子组件实例化的时，获取父组件传入的slot的标签内容，存放在vm.$slot中，当执行渲染时，遇到slot标签，使用$slot中的内容替换。
  7. 过滤器的作用，如何实现 使用filters来过滤数据，不修改数据，改变用户看到的输出
       <li>商品价格：{{item.price | filterPrice}}</li>
   filters: {
       filterPrice (price) {
       return price ? ('￥' + price) : '--'
   }
}
  8. 如何保存页面当前状态（也就是组件的状态，例如组件缓存）
    （1）前组件会被卸载
    1.将状态存储在LocalStorage / SessionStorage （状态通过json方法存储相当于深拷贝，深拷贝缺点会有不可拷贝的对象）
    2.路由传值：vue-router的link组件的prop-to属性
    （2）前组件不会被卸载
    1.单页面渲染：要切换的组件作为子组件全屏渲染，父组件中正常储存页面状态
    2.keep-alive缓存
  9. 常见的事件修饰符 .stop：阻止事件冒泡
    .prevent: 防止执行预设的行为
    .capture：与事件冒泡的方向相反，事件捕获由外到内
    .self：只会触发自己范围内的事件，不包含子元素
    .once：只会触发一次
  10. v-if v-show v-html原理
    v-if和v-show的区别： 1.v-if是动态的向dom树内添加或者删除，v-show通过设置dom元素的display控制显隐
    2.v-if切换有局部编译的过程，过程中合适的销毁和重建内部的事件监听和子组件；v-show只做简单的基于css的切换
    3.v-if惰性的，只有条件第一次变真才局部渲染；v-show无论首次条件都会被编译，然后被缓存
    4.v-if更高的切换消耗，适合条件不太改变的；v-show更高的初始渲染，适合频繁切换的
    v-html：设置innerHTML为v-html的值
  11. v-model如何实现，语法糖实际是什么？
    v-model是v-bind + v-on的语法糖，就是v-bind + v-on的简写，它实现的是双向数据绑定。
  12. data为什么是一个函数而不是对象？
    如果是对象的话可能会出现多个实例共用一个data对象，状态变更会影响所以实例；而采用函数形式，在initData的时候会返回全新的data对象，规避了多实例之间的状态污染情况
  13. keep-alive的理解，如何实现，具体缓存什么？
    如果需要在切换组件的时候，保存一些组件的状态防止多次渲染，可以用keep-alive去包裹。
    三个属性：include（匹配 会被缓存）exclude（匹配 不被缓存） max（最多缓存数）
  14. $nextTick的原理和作用
    主要作用：下次DOM更新循环结束之后执行延时回调
    原理：将传入的回调函数包装成宏微任务加入到Vue异步队列
  15. vue中给data中的对象添加一个新的属性时会发生什么？如何解决？
    直接添加是不会有响应式的，因为数据劫持是在实例初始化的时候进行的，后续添加的新属性，vue并不知道要进行处理 解决：vue2使用vue.set()，在Vue3中是ref或reactive对象的方法
  16. vue中封装的数组方法有哪些，如何实现页面刷新
    pop（移除数组最后一个）、push(向数组末尾添加)、shift（移除第一个）、unshift（添加到开头）、splice（从数组中添加或移除元素）、sort（排序）、reserve（颠倒顺序）
    如何实现：通过重写数组中的原生方法：首先获取到这个数组的Observer对象（即__ob__），如果有新的值，就调用observeArray继续对新的值观察变化（即通过target__proto__ == arrayMethods来改变了数组实例的型），然后手动调用notify，通知渲染Watcher，执行update。
  17. vue单页应用与多页应用的区别
    单页面：只有一个主页面的应用，一开始只加载一次js和css等资源，单页应用跳转就是切换组件，仅刷线局部资源（常用pc官网、购物网站）
    多页面：多个独立页面，每个页面重复加载js、css等资源（常用app、客户端）
  18. vue template 到 render 的过程（即：vue编译器的工作原理）
    vue中编译器会先对template解析，这一步称为parse，结束后会得到一个js对象，称为抽象语法树ast，然后对ast进行深加工的转换过程，这步为transform，最后将前面得到的ast生成js代码，也就是render函数。
    vue中编译器的执行时刻？
    如果使用webpack环境，即vue预打包环境，这时候的编译的执行时刻是在打包阶段，即预编译；如果是非运行时版本即携带编译器版本，编译器会在运行时工作：发现一个组件有模版没有渲染函数，就会去编译模版，将其转换为渲染函数，是发生在组件创建阶段。
    react中有没有编译器？没有
  19. vue data中某一个属性的值发生变化后，视图会立即同步执行重新渲染吗？
    不会立即同步执行重新渲染，它会开启一个异步更新队列。因为在一个事件循环中，数据可能会被多次修改，如果每次修改都立刻渲染会导致不必要的性能开销，通过异步更新队列一次性地进行视图更新（通常在当前事件循环的微任务阶段）
  20. 简述mixin、extends的覆盖逻辑？
    mixin：把多个组件共用的代码逻辑提取成一个混入对象
    extends：创建类似于原始组件的派生组件
    覆盖逻辑：
    1. 当前组件的选项：组件自身定义的选项拥有最高优先级
    2. extends中的选项：如果在extends中定义了选项，他们会与当前组件的选项合并，如果出现冲突，当前组件的选项会覆盖
    3. mixin中的选项：如果使用mixin，它中定义的选项会与当前组件的选项合并，如果出现冲突，当前组件的选项会覆盖
  21. 子组件可以直接改变父组件的数据么？
    不可以，维护父子组件的单向数据流。只能通过$emit子组件向父组件传递数据或通知。
